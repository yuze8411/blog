# 个人博客项目
**文件名设计**
  文件夹均为小写开头的驼峰模式
  组件名为大写开头的驼峰模式
**结构含义**
  /api 实现vercel代理
  /src/api 存放api文件
  /src/assets 存放静态文件，主要是图片和css
  /src/components 存放组件
  /src/views 存放路由组件
  /src/router 存放路由文件
  /src/stores 存放pinia的文件
**技术选用**
  前端：
    主体：vue3+pinia+vue-router
    请求：axios
    视图：echarts图表+particles.js粒子
    组件库：element-plus
    其它：和风天气—天气查询
  后端：

  部署：
    vercel
